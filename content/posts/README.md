# Beiträge für Soul Studio

Jede Datei in diesem Ordner (`.md`, `.txt` oder `.html`) ist ein Beitrag.
Soul Studio liest den Inhalt, entscheidet zwischen Video und Bild und produziert
das passende Asset mit deiner Soul ID. Bereits verarbeitete Beiträge stehen in
`soul-studio/state/processed.json` und werden nicht erneut produziert.

Dateien, die mit `_` beginnen, werden ignoriert.
