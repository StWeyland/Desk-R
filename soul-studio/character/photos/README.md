# Fotos für deine Soul ID

Lege hier 5 bis 20 Fotos von dir ab (jpg/png/webp). Sie werden nicht eingecheckt.

Was gut funktioniert:
- Gesicht klar erkennbar, scharf, gut ausgeleuchtet
- verschiedene Blickwinkel (frontal, leicht seitlich), verschiedene Lichtstimmungen
- neutrale und freundliche Mimik gemischt
- keine Sonnenbrille, keine anderen Personen im Bild, keine starken Filter

Dann: `python -m soul_studio soul create --name steffi`
